# TR-002 — Premature truncation understates net revenue

**Type:** deliberately seeded defect; **impact:** incorrect net sales; **classification:** business-rule failure despite successful execution.

## Reproduction
Run `python -m pytest -q tests/test_business_rules.py`. The negative-path test proves that `faulty_transform_sales` differs from the separately approved target values. To inspect faulty code, open `pipeline/transform_lab.py`.

## Expected vs actual (synthetic)
- **T-2001:** 1799 cents expected; 1700 cents faulty.
- **T-2002:** 667 cents expected; 600 cents faulty.
- **T-2004:** 2400 cents expected; 2400 cents faulty.
- **Aggregate:** 4866 cents expected; 4700 cents faulty; **$1.66 understatement** with equal row counts.

## Root cause
The demonstration implementation uses `int` on a decimal dollar total **before** conversion to cents, discarding fractional dollars rather than rounding the line total to the nearest cent using the required policy.

## Decision
Do not publish results from the buggy transformation. Fix the rule, verify independent per-row and aggregate expectations, rerun the affected partition and retain the evidence. A green test run that demonstrates detection is not approval to deploy the deliberately broken algorithm.
